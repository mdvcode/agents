# Agent Workspace

## Purpose
`/Users/user/agents` is the local operating base for AI coding agents.

## Main Areas
- `AGENTS.md`: repository policy and safety rules.
- `.agents/prompts/`: role prompts for planner, implementer, reviewer, and related agents.
- `.agents/skills/`: reusable local workflows.
- `docs/`: durable documentation and memory.
- `docs/issues/`: per-GitHub-issue journals.
- `docs/wiki/`: curated project knowledge.
- `docs/memory/`: daily/topic/scratchpad memory.
- `docs/graph/`: maps of workflows, files, risks, and agents.
- `artifacts/`: current-task workbench.
- `schemas/`: artifact validation schemas.
- `scripts/validate_artifacts.py`: local artifact validator.

## Current Rule
Artifacts are temporary; docs are durable.
