# Project Privacy Policy

## Classification
- Privacy level: private coding challenge.
- Default publication rule: private memory stays in `/Users/user/agents`.

## Allowed In The Target Project
- Assignment-scoped application code and tests.
- Sanitized implementation notes requested by the assignment.

## Not Allowed In The Target Project
- Harness run artifacts, agent traces, private memory, prompts, or internal reasoning.
- Secrets, credentials, private URLs, or unrelated personal data.

## Submission Rules
- Keep the repository private unless the user explicitly chooses otherwise.
- Submit only reviewed source changes, tests, and Git history.
- Do not publish or push automatically.
