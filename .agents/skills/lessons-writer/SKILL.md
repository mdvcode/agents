# Lessons Writer Skill

## Rules
- When a failure repeats or reveals a stable rule, append a lesson.
- Lessons must be concise, actionable, and pattern-based.
- Stable repository-wide lessons may also be summarized in `AGENTS.md`.
- Compare current failures against previous lessons before closing a task.
